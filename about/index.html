一些 Q&A

Q1 这个网站的组成？

如你所见，这个网页是使用 Hexo 框架搭建的，主题为 Cupertino，托管在 GitHub Pages 上。评论系统为Giscus。

Q2 为什么从 Mizuki 换到 Hexo + Cupertino？

说起来其实也赖我——没有充足的资金和精力去维护这个 Blog （主要就是没钱） ，所以只能选 GitHub Pages 方案托管。

之前的 Mizuki 主题虽然美观强大（相册、时间线、音乐播放器一应俱全），但也带来了一个副作用：加载资源太多。更何况我之前还在里面塞了个 LXGWWenKai 字体，对网络的要求变得极高，而 GitHub 的访问速度嘛……你懂的。

实在忍受不了这种速度了，所以换成了现在这套更轻量的方案。

Q3 为什么叫xjhjtzac？

因为小时候我玩Minecraft。当时正值1.16下界更新。Mojang更新了下界合金，所以我当时网名叫“下界合金套装”。

后来，觉得这个名有点中二，就取每个字首字母，变成了”xjhjtz”，这也是我Github用户名的由来。

再后来，由于我学过一段时间信息学竞赛，当时我打CSP-J时，为了吉利，在名字后加了“AC”。这就是“xjhjtzac”的由来。

Q4 是否配置了什么网站追踪器？

是的。
但有且仅有 Umami 一个。他是一个开源的、轻量的网站分析工具。不会收集任何敏感信息（你的IP，MAC地址、真实地址等）。所有收集到的信息都是匿名的，并且只会用于网站访问量统计。其不使用Cookie。开源意味着完全的透明，你可以在Umami的Github仓库查看全部代码。所以，你可以放心访问本站。
