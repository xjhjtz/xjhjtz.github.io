About This Webpage

如你所见，这个网页是使用 Hexo 框架搭建的，主题为 Cupertino，托管在 GitHub Pages 上。

为什么从 Mizuki 换到 Hexo + Cupertino？

说起来其实也赖我——没有充足的资金和精力去维护这个 Blog（主要就是没钱），所以只能选 GitHub Pages 方案托管。

之前的 Mizuki 主题虽然美观强大（相册、时间线、音乐播放器一应俱全），但也带来了一个副作用：加载资源太多。更何况我之前还在里面塞了个 LXGWWenKai 字体，对网络的要求变得极高，而 GitHub 的访问速度嘛……你懂的。

实在忍受不了这种速度了，所以换成了现在这套更轻量的方案。
