Twikoo评论区仿waline样式美化教程

说明 本教程面向 Twikoo 2.0，写的是把 Twikoo 换成 Waline 的外观，绝对不是换成把评论系统换成 Waline 。基准为 Twikoo 2.0.12 + @waline/client 3.16.0，跨大版本请先自查 DOM。

前言

我的博客评论区原来照着别人的 Twikoo 美化抄，Twikoo 从 1.7 升到 2.0 后旧 CSS 全部失效。原因是 2.0 把内部 DOM 和类名整套换成了 tk- 前缀 BEM，网上多数教程还停在 1.7 的 .el-* 时代。于是我让“大肥鱼”按 Waline 官方 waline.css 重写了一遍，逐条翻译到 Twikoo 2.0 的真实 DOM 上。效果如下。

原版的waline评论输入框是没有头像的，但是我加了一个。

自定义样式

整块 CSS 不依赖任何博客主题，想换配色只改 token 段即可。

如何使用

在自己的主题 CSS 里注入一次即可：

你的主题 放哪喵
Hexo Butterfly source/css/_custom/custom.css（或 inject.head 里塞 <style>）
Hexo Fluid 「自定义 CSS」配置项
Hexo Volantis / Solitude / Redefine / Stellar 各自的自定义 CSS / inject 配置
其他所有 主题的「自定义代码 / 注入 body 末尾」处塞一个 <style>

注入位置尽量靠后，body 末尾优于 head。如果只能塞 head，就把选择器再补一层重复类提权，比如 .twikoo .tk-submit → .twikoo .tk-submit.tk-submit。

Twikoo 2.0 的样式是运行时注入的，会插在你的自定义 CSS 后面。如果样式被盖，优先检查权重和加载顺序。也可以使用 twikoo.nocss.js + 官方 twikoo.css，或干脆不用它的 CSS，这样选择器可以写得简单些。

验收

改完样式一定一定一定要量计算样式，靠肉眼是不好的。权重被盖、变量没解析出来这种静默失败，肉眼是几乎看不太出来的。

这里给出console脚本，粘到浏览器 F12 控制台里回车即可打印出各个关键元素的计算样式，和预期值对比。

预期：面板白底 / 1px 边框 / 12px 圆角 / 无阴影；头像 52px 圆形；输入框 0 边框透明；编辑器 min-height ≥ 100px；发送钮接近 rgb(0, 113, 227)；评论之间 dashed。

如果某一项没生效，按这个顺序查说不定能解决：

这段是deepseek给的建议

  1. F12 选中元素 → Styles 面板，从下往上找划掉的规则；
  2. 盖你的是 .twikoo .xxx → 把你的选择器加长一层；
  3. 盖你的是 0,5,0 那种复合选择器（目前只有头像尺寸）→ 只能 !important；
  4. 什么都没盖但值也不对 → 变量没解析出来，检查 getComputedStyle(document.body).getPropertyValue('--twk-theme') 是不是空串。
