# Github那些实用 / 有趣的项目推荐

## 前言

最近一直在逛Github，偶然间看到了一些非常实用或者有趣的项目，于是我就想着整理出来。

---

## 1.HowToCook

- 截至**2026年3月24日**，GithubStar数量**99k**个

- 项目地址:   [Anduin2017/HowToCook: 程序员在家做饭方法指南](https://github.com/Anduin2017/HowToCook)

这是一个极其实用的程序员在家做饭方法指南，收录了多达400余种菜品的制作方法。涵盖早餐、荤素菜、主食、水产类等多种菜肴。最让人舒服的是，菜谱内完全没有让人感到疑惑的模糊词语（如"适量"等）。可以说，每一个菜谱的详细程度堪比SOP。同时，索引会按照难度划分菜谱，极大的方便了在家做饭。值得一提的是，本项目有一些衍生作品，如[whatToEat](https://github.com/ryanuo/whatToEat)与[HowToCookOnMiniprogram](https://github.com/LeeJim/HowToCookOnMiniprogram)等。

## 2.Mizuki

- 截至**2026年3月24日**，GithubStar数量**1.3k**个

- 项目地址：[matsuzaka-yuki/Mizuki: 下一代Material Design 3 博客主题(Astro驱动)](https://github.com/matsuzaka-yuki/Mizuki)

- 项目文档：[Mizuki Next Theme](https://docs.mizuki.mysqil.com/)

这是一个极其美观强大的博客主题，支持多种部署方法，并且还有完备的官方文档。如果你正在寻找一款既美观又功能强大的博客模板，Mizuki 无疑是一个值得考虑的选择。同时，他还具备基于**Pagefind**的全文搜索功能。自带现代化**Twikoo**评论系统。值得一体的是，其采用**现代化技术栈**，基于 **Astro** 和 **Tailwind CSS** 构建，确保高性能和灵活的样式定制能力。

## 3.CEF Detector X

- 截至2026年3月25日，GithubStar数量**2.5k**个

- 项目地址：[ShirasawaSama/CefDetectorX](https://github.com/ShirasawaSama/CefDetectorX)

这是一个 Windows 工具，用来一键扫描电脑里所有基于 Chromium Embedded Framework (CEF) 的应用——比如 Electron、NW.js、CefSharp 等。它会列出这些程序、统计它们占用的总空间，并按大小排序，让你一眼看清“CEF 们”是怎么悄悄吃掉硬盘的。还有背景音乐、高分辨率图标等小彩蛋，~~最让人绷不住的是，据说有人在他的前作提了个issue，于是这个项目也被用Election重写了一遍。~~

## 4.Chinese-programmer-wrong-pronunciation

- 截至2026年3月25日，GithubStar数量**23.2k**个

- 项目地址：[shimohq/chinese-programmer-wrong-pronunciation](https://github.com/shimohq/chinese-programmer-wrong-pronunciation)

这是一个收录了中国程序员最容易读错的技术单词的开源项目，由石墨文档团队维护。它列出了像 `Git`、`nginx`、`Vue`、`Linux`、`cache` 等常见术语的正确发音（带🔊可点击收听）、典型错误发音和中文释义，方便随时查阅。此外，项目还衍生出了浏览器扩展、独立网页版和 iOS 应用，非常实用了属于是。而且他的标准发音指向**网易有道词典**，保证标准。

## 5.BongoCat

- 截至2026年3月25日，GithubStar数量19.7k个

- 项目地址：[ayangweb/BongoCat](https://github.com/ayangweb/BongoCat)

这是一款开源的跨平台桌面互动宠物，基于 Tauri 构建，支持 macOS、Windows 以及 Linux (X11)。它会实时响应你的键盘、鼠标或手柄操作，同步做出拍打、敲击等生动动作，为桌面增添不少趣味。  
除了默认的猫咪形象，你还可以导入自定义模型，打造专属伙伴；项目还提供了模型转换工具和专门的模型分享仓库（Awesome-BongoCat），方便大家交流创意。  
整个应用完全开源，离线运行，不收集任何用户数据，既可爱又安心。如果你想要一只会在你敲代码、玩游戏时陪你互动的桌面小宠物，BongoCat 是个干净又好玩的选择。
